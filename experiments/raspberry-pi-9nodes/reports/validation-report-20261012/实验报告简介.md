# 实验报告简介

本报告针对递归 DNS 解析过程中受管解析器身份难以随单次查询核验的问题，介绍带外身份认证系统的实现与实验验证成果。系统保持标准 DNS 报文格式，通过独立身份状态与查询执行证据，对候选参与声明进行身份检查，并将认证决定绑定至最终响应和持久化授权状态，限制响应替换与授权复用。

实验在九角色物理平台开展，覆盖正常功能、身份状态、响应绑定、服务故障与性能五类问题。RQ1 的11个条件共2,200个测量 Root 满足功能检查，涵盖递归深度、缓存终止、重试、负向回答及传输回退。RQ2 的1,700个负向案例在指定入口均被拒绝，其中200个为真实 DNS 决策，1,500个为隔离生产函数案例，另记录30次撤销与重新激活发布过程。

RQ3 完成700个本地负向案例、70个正常对照及24,000个组件构造/分组，支持指定入口的精确响应检查和 Root 授权非复用。四个历史多签名方构造未满足拒绝预期，作为组件接受案例保留，未展示客户端可见绕过。RQ4 的302次故障活动包含151次明确拒绝、102次预期继续和49次不确定超时；七个独立恢复块共700个查询成功。

RQ5 完成26条件、130对、260块和30,600个测量请求，对比原生与认证部署及串行、流水线调度。默认1 QPS 下，D3 hot/cold成功回答 P50 的成对倍率为5.95–9.17，反映认证部署整体开销，流水线没有一致加速。全部133个测量失败均保留，near 条件有效回答为480/600，其中一个块为0/120。

报告结合原始记录、抓包、状态快照和完整性校验，形成可追溯的分项验证结论。现有证据支持受控配置与信任前提下的身份政策检查、响应关联和故障恢复，为甲方技术评审及导师科研审阅提供依据；完整真实执行认证、生产容量和长期稳定性仍未建立，不替代正式验收。
